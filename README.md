# Biomedical & Health Systems Modeling — ENGR 8130

This repository contains computational modeling exercises, simulations,
and weekly assessments completed for **ENGR 8130: Biomedical & Health
Systems Modeling**.

The goal of these projects is to explore how mathematical models,
physiological assumptions, measurement conditions, and signal-processing
choices affect conclusions about biomedical systems.

## Weekly Assessments

| Week | Modeling Topic | Main Focus |
|------|----------------|------------|
| Week 1 | Biomedical Modeling Foundations | Model assumptions and physiological interpretation |
| Week 2 | Biomedical System Modeling | Building and testing computational models |
| Week 3 | Physiological Feedback & Homeostasis | Feedback gain, delay, stability, and oscillation |
| Week 4 | Physiological Signal Processing | Sampling rate, noise, filtering, and measurement artifacts |
| Week 5 | Hidden-State Estimation | Estimating physiological states from noisy and incomplete observations |

*This repository will be updated as new weekly assessments are completed.*

## Repository Organization

Each weekly folder contains the materials needed to reproduce that week's
computational experiments, including:

- Python code or Jupyter notebooks
- Model parameters and assumptions
- Generated figures
- Experimental and surprise-challenge results
- A README explaining the model and key findings
